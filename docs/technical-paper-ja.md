# クリスタ原稿のレイヤー別変換と線画の検証

CLIP Drop v0.1.0 · 習作・ベータ版の技術資料

## 要旨

CLIP STUDIO PAINT の .clip を読み取り、中心線と輪郭線を含む SVG、レイヤー付き PSD、合成 PNG を生成する。クリスタ EX 4.1.4 で作成した同一画のベクター版・ラスター版と、ラスター線画にベクター図形を重ねた混在版で、レイヤーごとの変換経路と出力を確認した。

## 変換

図形の読み取りには、ファイル内のレイヤー ID とストロークを用いる。３次ベジェの両端 $P_0,P_1$ と制御点 $C_0,C_1$ から、SVG の中心線を次式で表す。

$$
B(t)=(1-t)^3P_0+3(1-t)^2tC_0+3(1-t)t^2C_1+t^3P_1,\qquad 0\le t\le1
$$

元データに３次ベジェ制御点があればその座標を使い、スプラインでは前後の点から接線を近似する。ストローク半径 $r$ と各点の幅係数 $w_i$ から、SVG の一定線幅を $W=2r\sum_{i=1}^n w_i/n$ とする。

ラスター層はキャンバスと交差する領域を読み込み、アルファの最小値・最大値がそれぞれ 0、255 の場合は $M(x,y)=\mathbf{1}[\alpha(x,y)\ge128]$ で半透明縁を処理する。VTracer で境界と色領域から閉じたパスを作る。SVG 内のグループに変換経路を記録する。

PSD はラスター層を画像として保存し、ベクター層はレンダリングして画像レイヤーにする。原寸の合成画像が CLIP に格納されていれば PNG に使用し、PSD の統合画像にも設定する。原寸合成を取得できない場合はレイヤーから再合成する。

## 検証

各 1,600 × 1,200 画素。クリスタの合成 PNG と SVG のレンダリング結果を輝度 128 未満で２値化し、線画マスク $A, B$ の一致を $J=|A\cap B|/|A\cup B|$ で計測した。

| 原稿 | SVG の経路 | 線画 IoU | PNG の RGBA 相違画素 |
| --- | --- | ---: | ---: |
| ベクター | 元ストローク | 92.2% | 0 |
| ラスター | 輪郭トレース | 94.5% | 0 |
| 混在 | 輪郭トレース、元ストローク | 94.1% | 0 |

混在版の SVG をクリスタに読み込み、両経路の制御点を選択した。ベクター版の PSD を Photoshop 2026 で開いて、用紙と線画が別レイヤーであることを確認した。

## 適用範囲

検証値は３件の線画に対する値で、異なる画材やカラー原稿への再現率を示さない。可変線幅、クリスタ固有のブラシ効果、調整レイヤー、マスクなどの編集互換には制約がある。初版の変換対象は Windows 64 ビット、2,400 万画素・250 レイヤーまでの静止画。Illustrator 用には SVG を書き出す。
