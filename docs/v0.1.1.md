# CLIP Drop v0.1.1 Beta / 習作・ベータ版

- Open the included PDF from the app's manual button. The same guide is available on the download page and as a release asset. / アプリの「マニュアル取得」から同梱PDFを開けます。配布ページとReleaseの添付ファイルからも入手できます。
- The Windows ZIP includes three .clip samples with vector, raster and mixed layers. / Windows版ZIPにベクター、ラスター、混在の検証用原稿３点を同梱しました。
- For an Illustrator document, open the exported SVG and save it as .ai in Illustrator. / Illustratorで .ai が必要な場合は、変換したSVGをIllustratorで開いて「別名で保存」を選びます。
