# CLIP Drop v0.1.0 Beta / 習作・ベータ版

- Experimental beta for opening a received .clip on Windows without Clip Studio Paint. Validation covers three line-art samples. / クリスタのないWindows PCで .clip を受け取ったときに使えるかもしれない習作です。線画３原稿で検証しました。
- Windows drag-and-drop conversion for .clip files. / .clipをドロップして変換するWindows版です。
- Export an SVG with paths, a layered PSD, and a full-sized PNG when the stored composite is available. / パスを持つSVG、レイヤー付きPSD、原寸合成画像がある場合は原寸PNGを保存します。
- Verified using vector, raster and mixed originals created in CLIP STUDIO PAINT EX 4.1.4. / クリスタEX 4.1.4で作ったベクター、ラスター、混在原稿で確認しました。
- Illustrator users can import SVG and save an AI file in Illustrator. / IllustratorではSVGを読み込み、Illustratorの保存操作でAIファイルにできます。
